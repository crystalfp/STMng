Match a structure against known “Prototype” and “Collection” structures

This module matches crystal structures against two collections of structures: known crystallographic “Prototypes” structures from the Encyclopedia of crystallographic prototypes and a “Collection” of interesting structures from various sources.

The “Prototype” structures are accessible as a Structure reader special collection. The prototype found is shown by its “mineral” tag field that, in the Aflow’s Encyclopedia of crystallographic prototypes, is identified as the “Notes” field. These values have been updated by inputs provided by Prof. Artem Oganov. If you find that any string could be made clearer or more precise, do not hesitate to contact the author.

The “Collection” structures are accessible as a Structure reader special collection.

For both sets the match is done using the Oganov Valle fingerprints (see the Compute fingerprints node) and the results are ordered by increasing cosine distance between fingerprints. Note that to compute the fingerprints all the atomic species are changed to hydrogen.

Controls

Common controls

Enable matching toggle Enable the matcher. Note that the process could be time consuming and computational heavy, so by default the module is disabled.
Show input details toggle Show the empirical formula of the loaded structure and its symmetry.
Similar structures table Show the matched structures. See below for a description.
Show color legend toggle Show the color legend for the distances. See below the color legend.
Matcher parameters button Toggle the visibility of the section where the parameters for the matcher could be adjusted.
Show matches button Open a secondary window to display the matchers results.

Matchers parameters

Collection neighbors slider Number of groups of distances for the structures returned from the collection. The groups are ordered by increasing cosine distance.

Similar structures list

Similar structures clickable text Together with the color coded distances between fingerprints, the entries from the prototype structure set show the “mineral” tags from the prototypes and the corresponding “Aflow UID” string. For the structures from the collection no extra information is given. If no match is found “No match found” is shown. Clicking on the entries opens the secondary window that shows the corresponding structure.

The color legend for the distances is:

  •   questionable relatives (distance over 0.15)
  •   distant relatives (distance: 0.12 - 0.15)
  •   related structures (distance: 0.04 - 0.12)
  •   identical structures (distance up to 0.04)

Credits

The Aflow project has made available the Encyclopedia of crystallographic prototypes which can be searched and loaded by part of the Aflow UID string or mineral name.

The prototypes database is described in:

  • H. Eckert, S. Divilov, M. J. Mehl, D. Hicks, A. C. Zettel, M. Esters. X. Campilongo and S. Curtarolo, The AFLOW Library of Crystallographic Prototypes: Part 4, Comp. Mat. Sci. 240, 112988 (2024). DOI: 10.1016/j.commatsci.2024.112988
  • D. Hicks, M. J. Mehl, M. Esters, C. Oses, O. Levy, G. L. W. Hart, C. Toher, and S. Curtarolo, The AFLOW Library of Crystallographic Prototypes: Part 3, Comp. Mat. Sci. 199, 110450 (2021). DOI: 10.1016/j.commatsci.2021.110450

The files in the Collection have been collected from various sources and provided by Prof. Artem Oganov.
