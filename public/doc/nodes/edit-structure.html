Edit-structure

Small editing of a loaded structure

Edit an existing structure by adding, deleting or changing its atoms.

To edit or delete an atom, select it in the viewer by Ctrl-click on it.

To remove selection, Ctrl-click on the viewer background.

When no atom is selected, an atom could be added by filling its characteristics.

Note. The atom selection interferes with the Measures node. As a consequence, the project should contains the Edit structure node or the Measures node but not both.

Controls

Select an atom /
Selected atom (index: n)		 readonly text If an atom is select it shows its index.
Atom type list Set/Change atom type. It should always be set.
Label text Set/Change atom label.
Chain text Optionally set/change atom chain.
Use fractional coordinates toggle Set how the coordinates should be interpreted.
x / fa numeric field X cartesian coordinate or Fa fractional coordinate of the atom.
y / fb numeric field Y cartesian coordinate or Fb fractional coordinate of the atom.
z / fc numeric field Z cartesian coordinate or Fc fractional coordinate of the atom.
Delete button After asking confirmation delete the selected atom. Disabled if no atom selected.
Change button After asking confirmation change the values of the selected atom to the ones entered. Disabled if no atom selected.
Add button After asking confirmation add an atom with the given characteristics. Disabled if an atom is selected.
Reset structure button After asking confirmation return the structure to the input, not edited, one. Disabled if no changes have been made.
